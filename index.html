About the algorithms

Each algorithm disperses agents so that every node ends up holding at most one. They differ in how a node is chosen and who does the looking.

Drop and Freeze

Runs in three phases per round. Probe out: the unsettled agents standing on a node fan out, one per distinct port, to look at a neighbour. Probe back: each returns carrying one bit — whether the node it saw was already occupied. Move out: if the current node is unoccupied one agent settles there and freezes, and the rest move on together through a port a probe reported empty. When no empty port is left the group backtracks along the port it first arrived by, so the walk is a DFS with the settled agents holding the tree.

Legacy baseline. Preserves the behaviour of this repository's original implementation. Not a literal port of a published algorithm. Flowchart and code · behaviour spec

Help by Scouts

Also a DFS, but settled agents help. A settled agent whose node can spare it vacates and travels with the unsettled group as a scout, which lets several ports be probed in the same round instead of one at a time. Scouts later retrace the tree in post-order and drop back onto the nodes they own, so the dispersion still ends one agent per node.

Legacy baseline. Preserves the behaviour of this repository's original implementation. Not a literal port of a published algorithm. Flowchart and code · behaviour spec

P1Tree

Builds a port-one tree: a spanning tree in which every node has at least one incident tree edge carrying port 1 at one of its two ends. Each edge is classified by the pair of port numbers at its ends — tp1, t11, t1q or tpq, where tpq is the only kind with port 1 at neither end — and the DFS prefers them in the order tp1 > t11 ~ t1q > tpq. A node reached only through a tpq edge cannot keep it as its parent, so it is parked as partiallyVisited and waits; when the DFS later arrives from that node's port-1 neighbour, the tree edge is swapped for the port-1 one and the node becomes ordinary. Agents settle one per node as the DFS discovers them, which is the dispersion.

Parallel probe: the scouts take a port each and step out together, then all return in the next round reporting what they found, so a neighbourhood search costs two rounds rather than two per port. The parent port is skipped. With fewer scouts than ports the assignment repeats.

Vacating: a settled agent whose node can spare it travels with the head as a scout, which is what keeps enough scouts to probe in parallel once every agent has settled. A closing retrace walks the tree in post-order and puts each scout back on the node it owns.

Implements Definition 1, Algorithm 2 (DFS_P1Tree), the parallel probe, vacating and retrace of Pattanayak, Kshemkalyani, Kumar, Molla and Sharma, Optimal Dispersion Under Asynchrony (arXiv:2507.01298). The scheduler here is synchronous, so these round counts are not the paper's O(k) epoch bound. Flowchart and code · implementation notes

RootedDisp

A depth-first search led by the agent with the largest ID; at each new node the smallest-ID explorer settles. Before every move the leader runs Probe(): the agents at its node each visit one neighbour, and a settler they find comes back with them as a helper and probes too, so the probers double each pass until one finds an unsettled neighbour or every port has been checked. The helpers then walk home through the port they came by, and the group moves forward to the unsettled node or back along its parent port. The run ends when the leader settles.

The line under the playback bar names each step's phase, the Probe() and pass it belongs to, and where the helpers are.

Implements Section 3 and Algorithm 1 of Sudo, Shibata, Nakamura, Kim and Masuzawa, Near-linear Time Dispersion of Mobile Agents (arXiv:2310.04376v3): O(k log τ) steps. Rooted placement only. implementation notes

Ports are numbered from 0 here, so the paper's port 1 is the port labelled 0 in the view above.
