## Drop and Freeze (legacy baseline)

Three phases per round, over the agents standing on each node. Unsettled agents fan out one per port to look at a neighbour, come back carrying one bit — does it have a settled agent — and then one of them settles where nobody has while the rest move on together through a port a probe reported empty. When every port has been tried the group backtracks through the settled agent's parent port, so the walk is a DFS whose tree is held by the settled agents.

It is meant for agents that all start on **one node**: from there, with no more agents than nodes, it always finishes. The code also accepts agents on several start nodes (as the Python reference did), but then a group can get stuck for good — see the notes.

`canonicalize_ports` is a compatibility decision rather than an algorithmic one: the Python reference replaced any supplied local port labels with canonical sorted-neighbour ones, so this port does too. It means Drop-and-Freeze ignores the port assignment the experiment asked for.

**Notes**

- **Several start nodes can stall the run.** "Empty" is read during the probe, and a start node's agent only settles later in the same round. So a group can move into another group's start node just as it becomes owned. Nobody settles there for this group, so it has no parent port to go back by: once that node's ports are used up, the group stays for good, and the run ends at the round limit with empty nodes left. Example: tree 0–1, 0–2, 1–3 with agents starting on 0, 0, 0 and 2 — two agents settle, two are stuck on node 2. The Python reference behaves the same way.
- No empty port does not always mean backtrack: the group stays and probes again next round whenever ports remain after the cursor that this round's probers (counting an agent that just settled) did not cover.
- "Empty" is read during the probe. In the same round a group standing on that neighbour may settle one of its agents there, so a group can move into a node that has just become owned.
- `validate_state` runs before the first round and after each of the three phases; the chart shows it once. A bad input, a failed traversal or a broken invariant returns an error instead of a result.
- Round limit: the rounds run as `1..=round_limit`. A run that settles in exactly the last round still ends Completed.

```rust
/// Runs Drop-and-Freeze while allowing callers to provide a metrics sink and
/// recorder.  The algorithm itself never depends on either observer.
///
/// # Errors
///
/// Returns an error when the graph is invalid, a start node is outside the
/// graph, or an invariant fails during a transition.
pub fn simulate_with<M: Metrics, R: Recorder>(
    graph: &PortGraph,
    starts: &[NodeId],
    round_limit: u64,
    metrics: &mut M,
    mut recorder: R,
) -> Result<SimulationRun<R::Output>, DropAndFreezeError> {
    if starts.len() > u32::MAX as usize {
        return Err(DropAndFreezeError::TooManyAgents(starts.len()));
    }
    for &node in starts {
        if node.index() >= graph.node_count() {
            return Err(DropAndFreezeError::InvalidStart(node));
        }
    }

    // Python `_init_ports` replaces any supplied local labels with canonical
    // sorted-neighbor ports.  Normalize before executing the transition rules.
    let graph = canonicalize_ports(graph)?;
    let mut state = SimulationState {
        agents: starts
            .iter()
            .copied()
            .map(DropAgentState::unsettled)
            .collect(),
        settled_agent_at: vec![None; graph.node_count()],
        node_status: vec![DropNodeStatus::Empty; graph.node_count()],
    };

    validate_state(&graph, &state)?;
    observe(metrics, &state);
    recorder.record(FrameLabel::Start, &state);

    let mut completed = all_settled(&state);
    for round in 1..=round_limit {
        if completed {
            break;
        }
        metrics.macro_round();
        metrics.logical_rounds(RoundKind::ProbeOut, 1);
        probe_out(&graph, &mut state, metrics);
        validate_state(&graph, &state)?;
        observe(metrics, &state);
        recorder.record(FrameLabel::ProbeOut { round }, &state);

        metrics.logical_rounds(RoundKind::ProbeBack, 1);
        probe_back(&graph, &mut state, metrics)?;
        validate_state(&graph, &state)?;
        observe(metrics, &state);
        recorder.record(FrameLabel::ProbeBack { round }, &state);

        metrics.logical_rounds(RoundKind::Movement, 1);
        move_out(&graph, &mut state, metrics)?;
        validate_state(&graph, &state)?;
        observe(metrics, &state);
        recorder.record(FrameLabel::MoveOut { round }, &state);

        completed = all_settled(&state);
    }

    let termination = if completed {
        Termination::Completed
    } else {
        Termination::RoundLimitReached { limit: round_limit }
    };
    Ok(SimulationRun {
        final_state: state,
        termination,
        trace: recorder.finish(),
    })
}
```

```rust
fn canonicalize_ports(graph: &PortGraph) -> Result<PortGraph, GraphError> {
    let mut edges = Vec::with_capacity(graph.edge_count());
    for source_index in 0..graph.node_count() {
        let source = NodeId(u32::try_from(source_index).expect("PortGraph node IDs fit in u32"));
        for (_, edge) in graph.ports(source) {
            if source < edge.neighbor {
                edges.push((source, edge.neighbor));
            }
        }
    }
    PortGraph::from_undirected_edges(graph.node_count(), &edges)
}
```

```rust
fn probe_out<M: Metrics>(graph: &PortGraph, state: &mut SimulationState, metrics: &mut M) {
    let (buckets, active) = occupancy(state);
    let mut moves = Vec::new();
    for node in active {
        let settled = state.settled_agent_at[node.index()];
        let mut unsettled: Vec<_> = buckets[node.index()]
            .iter()
            .copied()
            .filter(|&agent| {
                Some(agent) != settled
                    && state.agents[agent.index()].status == DropStatus::Unsettled
            })
            .collect();
        if unsettled.is_empty() {
            continue;
        }
        for &agent in &unsettled {
            let value = &mut state.agents[agent.index()];
            value.probe_home = None;
            value.probe_port = None;
            value.probe_result_empty = None;
        }
        if settled.is_none() && unsettled.len() == 1 {
            continue;
        }
        let ports = ordered_ports(graph, node);
        if ports.is_empty() {
            continue;
        }
        let start = settled.map_or(0, |agent| state.agents[agent.index()].next_port_to_try);
        if start >= ports.len() {
            continue;
        }
        unsettled.sort_unstable();
        for (agent, &port) in unsettled.iter().zip(ports[start..].iter()) {
            let Some(edge) = graph.traverse(node, port) else {
                continue;
            };
            let value = &mut state.agents[agent.index()];
            value.probe_home = Some(node);
            value.probe_port = Some(port);
            value.probe_result_empty = None;
            value.status = DropStatus::SettledWaiting;
            metrics.port_probe();
            metrics.probe_out_traversal();
            metrics.agent_moves(1);
            moves.push(ProbeMove {
                agent: *agent,
                destination: edge.neighbor,
            });
        }
    }
    for movement in moves {
        state.agents[movement.agent.index()].node = movement.destination;
    }
}
```

```rust
fn ordered_ports(graph: &PortGraph, node: NodeId) -> Vec<PortId> {
    let mut ports: Vec<(PortId, PortEdge)> = graph.ports(node).collect();
    ports.sort_by_key(|(port, edge)| (EdgeType::of(*port, edge.remote_port).priority(), port.0));
    ports.into_iter().map(|(port, _)| port).collect()
}
```

`probe_back` — [crates/ccm-algorithms/src/drop_and_freeze.rs:408](https://github.com/drdebmath/CCMModel/blob/main/crates/ccm-algorithms/src/drop_and_freeze.rs#L408-L439)

```rust
fn probe_back<M: Metrics>(
    graph: &PortGraph,
    state: &mut SimulationState,
    metrics: &mut M,
) -> Result<(), DropAndFreezeError> {
    let mut moves = Vec::new();
    for index in 0..state.agents.len() {
        let agent =
            ccm_core::AgentId(u32::try_from(index).expect("agent IDs fit in the dense u32 domain"));
        if state.agents[index].status != DropStatus::SettledWaiting {
            continue;
        }
        let source = state.agents[index].node;
        state.agents[index].probe_result_empty =
            Some(state.settled_agent_at[source.index()].is_none());
        state.agents[index].status = DropStatus::Unsettled;
        if let Some(home) = state.agents[index].probe_home {
            let Some(port) = local_port_to(graph, source, home) else {
                return Err(DropAndFreezeError::Invariant(
                    InvariantViolation::InvalidTraversal,
                ));
            };
            metrics.probe_back_traversal();
            metrics.agent_moves(1);
            moves.push((agent, home, port));
        }
    }
    for (agent, destination, _incoming_port) in moves {
        state.agents[agent.index()].node = destination;
    }
    Ok(())
}
```

```rust
#[allow(clippy::too_many_lines)]
fn move_out<M: Metrics>(
    graph: &PortGraph,
    state: &mut SimulationState,
    metrics: &mut M,
) -> Result<(), DropAndFreezeError> {
    let (buckets, active) = occupancy(state);
    let mut movers_by_node = vec![Vec::new(); state.node_status.len()];
    let mut active_with_movers = Vec::new();
    for node in active {
        let settled = state.settled_agent_at[node.index()];
        let movers: Vec<_> = buckets[node.index()]
            .iter()
            .copied()
            .filter(|&agent| {
                Some(agent) != settled
                    && state.agents[agent.index()].status == DropStatus::Unsettled
            })
            .collect();
        if !movers.is_empty() {
            active_with_movers.push(node);
            movers_by_node[node.index()] = movers;
        }
    }

    let mut newly_settled = vec![false; state.node_status.len()];
    for &node in &active_with_movers {
        if state.settled_agent_at[node.index()].is_some() {
            continue;
        }
        let agent = movers_by_node[node.index()].remove(0);
        let entry_pin = state.agents[agent.index()].entry_pin;
        let parent_port = entry_pin.filter(|&port| graph.traverse(node, port).is_some());
        state.agents[agent.index()].status = DropStatus::Settled;
        state.agents[agent.index()].parent_port = parent_port;
        state.agents[agent.index()].next_port_to_try = 0;
        state.settled_agent_at[node.index()] = Some(agent);
        state.node_status[node.index()] = DropNodeStatus::Occupied;
        newly_settled[node.index()] = true;
        metrics.settlement();
    }

    let mut planned = Vec::new();
    for &node in &active_with_movers {
        let movers = &movers_by_node[node.index()];
        if movers.is_empty() {
            continue;
        }
        let Some(settled) = state.settled_agent_at[node.index()] else {
            continue;
        };
        let ports = ordered_ports(graph, node);
        if ports.is_empty() {
            continue;
        }
        let cursor = state.agents[settled.index()].next_port_to_try;
        let mut scouts = movers.clone();
        if newly_settled[node.index()] {
            scouts.push(settled);
        }
        let mut empty_ports = Vec::new();
        for agent in scouts {
            let value = state.agents[agent.index()];
            if value.probe_home != Some(node) || value.probe_result_empty != Some(true) {
                continue;
            }
            let Some(port) = value.probe_port else {
                continue;
            };
            if graph.traverse(node, port).is_some() && !empty_ports.contains(&port) {
                empty_ports.push(port);
            }
        }
        empty_ports.sort_by_key(|port| {
            ports
                .iter()
                .position(|candidate| candidate == port)
                .unwrap_or(usize::MAX)
        });

        let chosen = empty_ports.iter().copied().find(|port| {
            ports
                .iter()
                .position(|candidate| candidate == port)
                .is_some_and(|index| index >= cursor)
        });
        if let Some(port) = chosen {
            let index = ports
                .iter()
                .position(|candidate| candidate == &port)
                .ok_or(DropAndFreezeError::Invariant(
                    InvariantViolation::InvalidTraversal,
                ))?;
            let edge = graph
                .traverse(node, port)
                .ok_or(DropAndFreezeError::Invariant(
                    InvariantViolation::InvalidTraversal,
                ))?;
            state.agents[settled.index()].next_port_to_try = index + 1;
            planned.push(MoveGroup {
                agents: movers.clone(),
                from: node,
                port,
                destination: edge.neighbor,
                backtrack: false,
            });
            continue;
        }

        let probed_count =
            scouts_for_count(state, node, movers, newly_settled[node.index()], settled);
        state.agents[settled.index()].next_port_to_try =
            core::cmp::min(ports.len(), cursor.saturating_add(probed_count));
        if state.agents[settled.index()].next_port_to_try < ports.len() {
            continue;
        }
        let Some(parent_port) = state.agents[settled.index()].parent_port else {
            continue;
        };
        let Some(edge) = graph.traverse(node, parent_port) else {
            continue;
        };
        state.agents[settled.index()].next_port_to_try = ports.len();
        planned.push(MoveGroup {
            agents: movers.clone(),
            from: node,
            port: parent_port,
            destination: edge.neighbor,
            backtrack: true,
        });
    }

    for group in planned {
        metrics.group_move(group.agents.len());
        if group.backtrack {
            metrics.backtrack();
        }
        metrics.agent_moves(group.agents.len() as u64);
        for agent in group.agents {
            let value = &mut state.agents[agent.index()];
            value.node = group.destination;
            let incoming = local_port_to(graph, group.destination, group.from).ok_or(
                DropAndFreezeError::Invariant(InvariantViolation::InvalidTraversal),
            )?;
            value.pin = Some(incoming);
            value.entry_pin = Some(incoming);
            value.probe_home = None;
            value.probe_port = None;
            value.probe_result_empty = None;
        }
    }
    Ok(())
}
```

```rust
fn scouts_for_count(
    state: &SimulationState,
    node: NodeId,
    movers: &[ccm_core::AgentId],
    include_settled: bool,
    settled: ccm_core::AgentId,
) -> usize {
    let mut ports = Vec::<PortId>::new();
    for &agent in movers {
        let value = state.agents[agent.index()];
        if value.probe_home == Some(node) {
            if let Some(port) = value.probe_port {
                if !ports.contains(&port) {
                    ports.push(port);
                }
            }
        }
    }
    if include_settled {
        let value = state.agents[settled.index()];
        if value.probe_home == Some(node) {
            if let Some(port) = value.probe_port {
                if !ports.contains(&port) {
                    ports.push(port);
                }
            }
        }
    }
    ports.len()
}
```

```rust
fn validate_state(graph: &PortGraph, state: &SimulationState) -> Result<(), DropAndFreezeError> {
    if state.settled_agent_at.len() != graph.node_count()
        || state.node_status.len() != graph.node_count()
    {
        return Err(DropAndFreezeError::Invariant(
            InvariantViolation::OwnershipIndexMismatch,
        ));
    }
    for (index, agent) in state.agents.iter().enumerate() {
        if agent.node.index() >= graph.node_count() {
            return Err(DropAndFreezeError::Invariant(
                InvariantViolation::InvalidAgentNode,
            ));
        }
        if let Some(home) = agent.probe_home {
            if home.index() >= graph.node_count() {
                return Err(DropAndFreezeError::Invariant(
                    InvariantViolation::InvalidTraversal,
                ));
            }
        }
        if let Some(port) = agent.parent_port {
            if graph.traverse(agent.node, port).is_none() {
                return Err(DropAndFreezeError::Invariant(
                    InvariantViolation::InvalidParent,
                ));
            }
        }
        if let Some(owner) = state.settled_agent_at[agent.node.index()] {
            if owner
                == ccm_core::AgentId(
                    u32::try_from(index).expect("agent IDs fit in the dense u32 domain"),
                )
                && agent.status != DropStatus::Settled
            {
                return Err(DropAndFreezeError::Invariant(
                    InvariantViolation::OwnershipIndexMismatch,
                ));
            }
        }
    }
    for (node, owner) in state.settled_agent_at.iter().enumerate() {
        if let Some(agent) = owner {
            let Some(value) = state.agents.get(agent.index()) else {
                return Err(DropAndFreezeError::Invariant(
                    InvariantViolation::OwnershipIndexMismatch,
                ));
            };
            if value.node.index() != node || value.status != DropStatus::Settled {
                return Err(DropAndFreezeError::Invariant(
                    InvariantViolation::OwnershipIndexMismatch,
                ));
            }
            if state.node_status[node] != DropNodeStatus::Occupied {
                return Err(DropAndFreezeError::Invariant(
                    InvariantViolation::OwnershipIndexMismatch,
                ));
            }
        } else if state.node_status[node] != DropNodeStatus::Empty {
            return Err(DropAndFreezeError::Invariant(
                InvariantViolation::OwnershipIndexMismatch,
            ));
        }
    }
    Ok(())
}
```

## Help by Scouts (legacy baseline)

Also a DFS, but settled agents help. A settled agent whose node can spare it vacates and travels with the group as a scout, so more agents share the probing of a node's ports. When nobody is left unsettled, the scouts walk the tree depth first and each drops back onto its own node when the group reaches it, so the run ends with one settled agent on each occupied node.

Like the Python reference it is rooted: placements on several start nodes are not supported (a test records the reference's failure on them).

**Notes**

- The order inside a step matters: `can_vacate` reads the node type that `update_node_type` has just set from the probe reports.
- An owner that vacates joins this step's move and the next step's probe — not the probe already done.
- Only when `can_vacate` says the owner stays can it have released the parent node's owner — the root's included — into the group.
- A scout is not always out until the retrace: if the group comes back to its node and it may no longer leave, it settles back in there.
- Every step spends logical rounds through `tick()`, and so does each move of the retrace; the first one past the limit ends the run as RoundLimitReached. Backtracking at the root is an error (`MissingParent`).

```rust
    fn run_transitions(&mut self) -> Result<(), HelpError> {
        self.observe();
        while self.unsettled.iter().any(|&value| value) {
            self.metrics.macro_round();
            let active = self.active_ids();
            let head = *active
                .first()
                .ok_or(HelpError::Invariant("empty active set"))?;
            let node = self.agents[head.index()].node;
            let owner = if let Some(owner) = self.physical_settler(node, None) {
                owner
            } else {
                let to_settle = self.occupants[node.index()]
                    .iter()
                    .copied()
                    .filter(|id| self.unsettled[id.index()])
                    .max()
                    .ok_or(HelpError::MissingSettler(node))?;
                self.settle(to_settle, node, head)?;
                self.tick(1)?;
                to_settle
            };
            if !self.unsettled.iter().any(|&value| value) {
                break;
            }
            self.agents[head.index()].previous = Some(owner);
            let scouts = self.active_ids();
            let next_port = self.parallel_probe(node, owner, &scouts)?;
            self.observe();
            self.update_node_type(node, owner)?;
            let status = self.can_vacate(node, owner)?;
            self.agents[owner.index()].status = status;
            match status {
                HelpStatus::Settled => self.vacated[owner.index()] = false,
                HelpStatus::SettledScout => self.vacated[owner.index()] = true,
                HelpStatus::Unsettled => {}
            }
            let moving = self.active_ids();
            if let Some(port) = next_port {
                self.agents[owner.index()].recent_port = Some(port);
                self.agents[head.index()].child_port = Some(port);
                let destination = self.move_group(&moving, node, port)?;
                self.metrics.logical_rounds(RoundKind::Movement, 1);
                self.tick(1)?;
                if let Some(destination_owner) = self.physical_settler(destination, None) {
                    let arrival = self.agents[head.index()].arrival_port;
                    if self.agents[destination_owner.index()].node_type
                        == NodeType::PartiallyVisited
                        && arrival == Some(PortId(0))
                    {
                        self.agents[destination_owner.index()].parent = Some(owner);
                        self.agents[destination_owner.index()].port_at_parent = Some(port);
                        self.agents[destination_owner.index()].parent_port = arrival;
                        self.agents[destination_owner.index()].node_type = NodeType::Visited;
                        self.agents[destination_owner.index()].depth =
                            self.agents[owner.index()].depth.saturating_add(1);
                    }
                }
            } else {
                let parent_port = self.agents[owner.index()]
                    .parent_port
                    .ok_or(HelpError::MissingParent(node))?;
                self.agents[head.index()].child_port = None;
                self.agents[owner.index()].recent_port = Some(parent_port);
                self.move_group(&moving, node, parent_port)?;
                self.metrics.backtrack();
                self.metrics.logical_rounds(RoundKind::Movement, 1);
                self.tick(1)?;
            }
        }
        self.retrace()?;
        Ok(())
    }
```

```rust
    fn parallel_probe(
        &mut self,
        node: NodeId,
        owner: AgentId,
        scouts: &[AgentId],
    ) -> Result<Option<PortId>, HelpError> {
        let parent_port = self.agents[owner.index()].parent_port;
        let ports: Vec<PortId> = self
            .graph
            .ports(node)
            .map(|(port, _)| port)
            .filter(|&port| Some(port) != parent_port)
            .collect();
        self.agents[owner.index()].probe_results.clear();
        if !ports.is_empty() && scouts.is_empty() {
            return Err(HelpError::Invariant("no scouts available for probe"));
        }
        for batch in ports.chunks(scouts.len().max(1)) {
            for (index, &port) in batch.iter().enumerate() {
                let scout = scouts[index];
                let edge_type = self.edge_type(node, port)?;
                let destination = self.move_agent(scout, node, port)?;
                self.metrics.port_probe();
                self.metrics.scout_operation();
                self.metrics.probe_out_traversal();
                let owner_at_destination = self.home_owner[destination.index()];
                let node_type = owner_at_destination
                    .map_or(NodeType::Unvisited, |id| self.agents[id.index()].node_type);
                let return_port =
                    self.agents[scout.index()]
                        .arrival_port
                        .ok_or(HelpError::InvalidPort {
                            node: destination,
                            port,
                        })?;
                self.move_agent(scout, destination, return_port)?;
                self.metrics.probe_back_traversal();
                self.agents[owner.index()].probe_results.push(ProbeResult {
                    port,
                    edge_type,
                    node_type,
                    owner: owner_at_destination,
                });
            }
            self.metrics.logical_rounds(RoundKind::Scout, 2);
            self.tick(2)?;
        }
        self.agents[owner.index()]
            .probe_results
            .sort_unstable_by_key(|result| result.port);
        self.recorder.record_event(
            self.steps,
            SimulationEvent::PhaseStarted {
                phase: Phase::Scout,
            },
        );
        Ok(self.agents[owner.index()]
            .probe_results
            .iter()
            .copied()
            .min_by_key(|result| Self::candidate_rank(*result))
            .filter(|result| Self::candidate_rank(*result).0 != 99)
            .map(|result| result.port))
    }
```

```rust
            .iter()
            .copied()
            .filter(|result| result.node_type == NodeType::Unvisited)

                self.agents[owner.index()].node_type = NodeType::Visited;
            }
        } else {
            self.agents[owner.index()].node_type = NodeType::Visited;
        }
        Ok(())
```

```rust
    fn can_vacate(&mut self, node: NodeId, owner: AgentId) -> Result<HelpStatus, HelpError> {
        self.metrics.vacate();
        self.metrics.logical_rounds(RoundKind::Vacate, 2);
        self.tick(2)?;
        let state = self.agents[owner.index()].clone();
        if state.parent_port.is_none() {
            return Ok(HelpStatus::Settled);
        }
        if state.node_type == NodeType::Visited
            || (state.node_type == NodeType::FullyVisited && !state.vacated_neighbor)
        {
            let destination = self.move_agent(owner, node, PortId(0))?;
            let other = self.physical_settler(destination, Some(owner));
            if let Some(other) = other {
                self.agents[other.index()].vacated_neighbor = true;
            }
            let return_port =
                self.agents[owner.index()]
                    .arrival_port
                    .ok_or(HelpError::InvalidPort {
                        node: destination,
                        port: PortId(0),
                    })?;
            self.move_agent(owner, destination, return_port)?;
            self.metrics.logical_rounds(RoundKind::Vacate, 2);
            self.tick(2)?;
            return Ok(if other.is_some() {
                HelpStatus::SettledScout
            } else {
                HelpStatus::Settled
            });
        }
        if state.node_type == NodeType::PartiallyVisited {
            return Ok(HelpStatus::SettledScout);
        }
        if state.port_at_parent == Some(PortId(0)) {
            let parent_port = state.parent_port.ok_or(HelpError::MissingParent(node))?;
            let parent_node = self.move_agent(owner, node, parent_port)?;
            let parent_owner = self.physical_settler(parent_node, Some(owner));
            if let Some(parent_owner) = parent_owner {
                if self.agents[parent_owner.index()].vacated_neighbor {
                    self.move_agent(owner, parent_node, PortId(0))?;
                } else {
                    self.agents[parent_owner.index()].status = HelpStatus::SettledScout;
                    self.vacated[parent_owner.index()] = true;
                    let ids = [owner, parent_owner];
                    self.move_group(&ids, parent_node, PortId(0))?;
                    self.agents[owner.index()].vacated_neighbor = true;
                }
            } else {
                self.move_agent(owner, parent_node, PortId(0))?;
            }
            self.metrics.logical_rounds(RoundKind::Vacate, 2);
            self.tick(2)?;
        }
        Ok(HelpStatus::Settled)
    }
```

```rust
    fn retrace(&mut self) -> Result<(), HelpError> {
        self.metrics.retrace();
        let mut vacated = self.active_ids();
        vacated.retain(|id| self.vacated[id.index()]);
        if vacated.is_empty() {
            return Ok(());
        }
        let mut tree = vec![Vec::<(NodeId, PortId)>::new(); self.graph.node_count()];
        for agent in &self.agents {
            if let (Some(home), Some(parent), Some(parent_port), Some(port_at_parent)) = (
                agent.home,
                agent.parent,
                agent.parent_port,
                agent.port_at_parent,
            ) {
                let parent_home = self.agents[parent.index()]
                    .home
                    .ok_or(HelpError::MissingParent(home))?;
                tree[home.index()].push((parent_home, parent_port));
                tree[parent_home.index()].push((home, port_at_parent));
            }
        }
        let start = self.agents[vacated[0].index()].node;
        let mut visited = vec![false; self.graph.node_count()];
        let mut stack = vec![(start, 0usize)];
        visited[start.index()] = true;
        self.settle_vacated_at(start);
        while !stack.is_empty() && self.vacated.iter().any(|&value| value) {
            let (node, index) = *stack.last().expect("stack non-empty");
            let next = tree[node.index()]
                .iter()
                .copied()
                .enumerate()
                .skip(index)
                .find(|(_, (neighbor, _))| !visited[neighbor.index()]);
            if let Some((edge_index, (neighbor, port))) = next {
                stack.last_mut().expect("stack non-empty").1 = edge_index + 1;
                let group = self.vacated_ids();
                self.move_group(&group, node, port)?;
                self.metrics.logical_rounds(RoundKind::Retrace, 1);
                self.tick(1)?;
                visited[neighbor.index()] = true;
                self.settle_vacated_at(neighbor);
                stack.push((neighbor, 0));
            } else {
                stack.pop();
                if let Some(&(parent, _)) = stack.last() {
                    let port = tree[node.index()]
                        .iter()
                        .find(|(neighbor, _)| *neighbor == parent)
                        .map(|(_, port)| *port)
                        .ok_or(HelpError::MissingParent(node))?;
                    let group = self.vacated_ids();
                    self.move_group(&group, node, port)?;
                    self.metrics.logical_rounds(RoundKind::Retrace, 1);
                    self.tick(1)?;
                }
            }
        }
        if self.vacated.iter().any(|&value| value) {
            return Err(HelpError::Invariant("retrace left vacated settlers"));
        }
        Ok(())
    }
```

## P1Tree

`DFS_P1Tree` from Pattanayak, Kshemkalyani, Kumar, Molla and Sharma, *Optimal Dispersion Under Asynchrony*. A DFS that builds a **port-one tree**: in a finished tree every vertex has an incident tree edge carrying port 1 at one of its ends. Among the ports probed so far, edges are preferred `tp1 > t11 ~ t1q > tpq`; a node that would be left without a port-1 tree edge is parked as `partiallyVisited` until its port-1 neighbour comes to claim it.

Two details carry the `O(k)` bound, and losing either makes the cost scale with the graph instead of with the agents:

- `neighbourhood_search` **stops at the first batch that finds somewhere to go**. Remark 1 bounds the search by the agent count, not the degree: at most `k` nodes are ever occupied, so when the degree allows, an empty neighbour turns up within the first `k-1` probed ports at the root and `k-2` elsewhere.
- `traverse` **stops at dispersion**. Section 5: "the process continues until no unsettled agents remain". The tree at that moment need not yet be a P1Tree — a parked node may still hold a `tpq` parent edge — and that is fine, because dispersion is the goal.

**Notes**

- Because the search stops at the first batch that finds something, the edge preference only applies among the ports probed so far: a port-1 edge on a port not yet probed can lose to an earlier batch's choice.
- A node reached by a `tpq` edge is parked only when its next choice would be another `tpq` edge or it has no candidate at all; if a port-1 edge turns up among the ports probed, it advances instead.
- After a move, `apply_can_vacate` and `apply_parent_vacate` both look at the node just left: it is the new node's parent.
- A leaf (no ports but the parent's) or a search with nobody to probe skips the probe steps: the search returns nothing and the node goes straight to the "none, all probed" branch.
- "Every agent settled?" is the stop rule of `simulate()` (`Stop::AtDispersion`). `simulate_with_stop` with `Stop::AtFullTree` runs on instead, and its only Completed exit is the root being popped (it can still stop at the round limit).

`traverse` — [crates/ccm-algorithms/src/p1tree.rs:344](https://github.com/drdebmath/CCMModel/blob/main/crates/ccm-algorithms/src/p1tree.rs#L344-L419)

```rust
    /// The `while S != {}` loop of Algorithm 2, with the stack realised by the
    /// parent pointers the settled agents hold.
    ///
    /// Under [`Stop::AtDispersion`], the default, the loop ends as soon as every
    /// agent has settled (Section 5). Under [`Stop::AtFullTree`] it runs until
    /// the root is popped, Algorithm 2's own termination, which is the walk
    /// that reconfigures any node still `partiallyVisited` and so makes the
    /// tree satisfy Definition 1. Popping the root also ends the default run
    /// if it comes first. Either way the caller runs Retrace afterwards.
    fn traverse(&mut self) -> Result<Termination, P1Error> {
        let mut rounds = 0_u64;
        loop {
            self.note_dispersion();
            // Section 5: "The process continues until no unsettled agents
            // remain." Once the tree has k vertices the construction is done,
            // and Retrace follows. Walking on past this point to finish the
            // whole spanning tree is not what the algorithm does, and on a graph
            // whose degree far exceeds the agent count that walk is what made
            // the cost scale with n instead of k.
            if self.stop == Stop::AtDispersion && self.dispersed_at_step.is_some() {
                return Ok(Termination::Completed);
            }
            if rounds >= self.round_limit {
                return Ok(Termination::RoundLimitReached {
                    limit: self.round_limit,
                });
            }
            rounds += 1;
            self.metrics.macro_round();

            // With no unsettled agent left there is nobody to settle at an
            // unvisited node, so those neighbours are not candidates. The head
            // can still enter a partiallyVisited node to reconfigure it.
            let can_settle = self.unsettled_count() > 0;
            let results = self.neighbourhood_search(can_settle)?;
            let next = Self::choose_next_edge(&results, can_settle);

            if let Some(chosen) = next {
                if self.must_defer(chosen) {
                    // Algorithm 2, lines 21-23: taking a tpq edge would
                    // leave this node with no port-1 incident tree edge, so
                    // it waits to be claimed by its port-1 neighbour.
                    self.node_type[self.head.index()] = NodeType::PartiallyVisited;
                    self.sync_node_type(self.head);
                    self.apply_can_vacate(self.head);
                    self.checkpoint(Phase::Movement);
                    if !self.backtrack()? {
                        return Ok(Termination::Completed);
                    }
                } else {
                    self.advance(chosen)?;
                }
            } else {
                // Algorithm 2, line 29 marks a node with no candidate edge
                // fullyVisited. That alone is not enough: a node discovered
                // through a tpq edge that happens to have no empty
                // neighbours would finish with only a tpq tree edge and
                // break Definition 1. Claim 3 of the paper is explicit that
                // such a vertex "is immediately marked partiallyVisited and
                // DFS backtracks", so that its port-1 neighbour can reach it
                // later and reconfigure it. A node therefore only becomes
                // fullyVisited once it holds a port-1 incident tree edge.
                self.node_type[self.head.index()] = if self.awaits_port_one() {
                    NodeType::PartiallyVisited
                } else {
                    NodeType::FullyVisited
                };
                self.sync_node_type(self.head);
                self.apply_can_vacate(self.head);
                self.checkpoint(Phase::Movement);
                if !self.backtrack()? {
                    return Ok(Termination::Completed);
                }
            }
        }
    }
```

`neighbourhood_search` — [crates/ccm-algorithms/src/p1tree.rs:440](https://github.com/drdebmath/CCMModel/blob/main/crates/ccm-algorithms/src/p1tree.rs#L440-L546)

```rust
    /// Section 4.2's parallel probe: the scouts fan out over the head's ports
    /// together and come back reporting what they saw.
    ///
    /// Ports are handed to scouts in increasing agent-ID order. When there are
    /// at least as many scouts as ports the whole search is two rounds, out and
    /// back, which is the `O(1)`-epoch neighbourhood search the paper's bound
    /// rests on; with fewer scouts the assignment repeats until every port has
    /// been probed. The parent port is skipped, as in the paper: the parent is
    /// known to be occupied and is reached by backtracking, not by probing.
    ///
    /// The paper's rules (R1)-(R3) exist to tell an *empty* neighbour from a
    /// *vacated* one, which is ambiguous because a vacated node's settled agent
    /// has left it to travel as a scout. Here the state is read directly, and
    /// the rules only charge the detour walks they require; see
    /// [`Self::probe_detour`].
    fn neighbourhood_search(&mut self, can_settle: bool) -> Result<Vec<ProbeResult>, P1Error> {
        let head = self.head;
        let degree = self.graph.degree(head).unwrap_or(0);
        let parent_port = self.parent[head.index()].map(|(_, port, _)| port);
        let ports: Vec<PortId> = (0..degree)
            .map(PortId)
            .filter(|port| Some(*port) != parent_port)
            .collect();
        let scouts = self.probe_party();
        let mut results = Vec::with_capacity(ports.len());
        if ports.is_empty() || scouts.is_empty() {
            return Ok(results);
        }

        for batch in ports.chunks(scouts.len()) {
            let moved = batch.len() as u64;

            self.metrics.logical_rounds(RoundKind::ProbeOut, 1);
            for (&port, &scout) in batch.iter().zip(scouts.iter()) {
                let edge = self
                    .graph
                    .traverse(head, port)
                    .ok_or(P1Error::InvalidPort { node: head, port })?;
                self.metrics.port_probe();
                self.metrics.probe_out_traversal();
                self.metrics.scout_operation();
                self.agents[scout].node = edge.neighbor;
                let state = self.state_of(edge.neighbor);
                // Rules (R2) and (R3): a scout that finds nobody home cannot yet
                // tell empty from vacated, and walks on to the port-1 neighbour
                // (and sometimes one further) to settle the question. The answer
                // is Lemma 5's, which is what the ownership index already holds,
                // but the walk is real and is charged here.
                let detour = self.probe_detour(edge.neighbor, edge.remote_port, state);
                for _ in 0..detour {
                    self.metrics.probe_out_traversal();
                    self.metrics.agent_moves(1);
                }
                results.push(ProbeResult {
                    port,
                    edge_type: EdgeType::of(port, edge.remote_port),
                    node_type: self.node_type[edge.neighbor.index()],
                    node_state: state,
                    owner: self.settled_at[edge.neighbor.index()],
                });
            }
            self.metrics.agent_moves(moved);
            self.checkpoint(Phase::ProbeOut);

            self.metrics.logical_rounds(RoundKind::ProbeBack, 1);
            for (&port, &scout) in batch.iter().zip(scouts.iter()) {
                let steps = self.graph.traverse(head, port).map_or(1, |edge| {
                    1 + self.probe_detour(
                        edge.neighbor,
                        edge.remote_port,
                        self.state_of(edge.neighbor),
                    )
                });
                for _ in 0..steps {
                    self.metrics.probe_back_traversal();
                }
                self.metrics.agent_moves(steps.saturating_sub(1));
                self.agents[scout].node = head;
            }
            self.metrics.agent_moves(moved);
            self.checkpoint(Phase::ProbeBack);

            // Stop as soon as a batch has turned up somewhere to go. Remark 1
            // of the paper bounds the search at "k-1 ports at the root node and
            // k-2 ports at a non-root node", not at the degree, and the reason
            // is pigeonhole: at most k nodes are ever occupied, so while any
            // agent is still unsettled some probed neighbour must be empty.
            //
            // Scanning every port instead made the cost scale with the degree
            // rather than with the agent count: 40 agents on a 4000-node
            // complete graph took 32357 rounds, where the DFS itself only made
            // 155 visits. The remaining ports are only worth probing when
            // nothing has been found, which is exactly the case that has to
            // rule out an empty neighbour before a node can be declared
            // finished.
            if Self::choose_next_edge(&results, can_settle).is_some() {
                break;
            }
        }

        if let Some(agent) = self.settled_at[head.index()] {
            self.agents[agent.index()]
                .probe_results
                .clone_from(&results);
        }
        Ok(results)
    }
```

```rust
    ///
    /// Once every agent has settled there is no travelling group left, and
    /// Section 4 has the node's own settled agent do the search. The head then
```

```rust
        let from = self.head;
        let edge = self
            .graph
            .traverse(from, chosen.port)
            .ok_or(P1Error::InvalidPort {
                node: from,
                port: chosen.port,

        let target = edge.neighbor;
        let was = self.node_type[target.index()];

        self.metrics.logical_rounds(RoundKind::Movement, 1);
        self.metrics.group_move(self.group_count());
        self.metrics.agent_moves(self.group_count() as u64);
        self.move_group_to(target);
        self.head = target;

        // The edge as seen from the target, which is the direction Definition 1
        // and the parent pointers are stated in.
        let from_target = EdgeType::of(edge.remote_port, chosen.port);

        match was {
            NodeType::Unvisited => {
                // Settle before recording the parent edge: the settled agent is
                // where the node's parent pointers live, so writing them first
                // wrote them nowhere.
                self.settle_highest_at(target);
                self.node_type[target.index()] = NodeType::Visited;
            }
            NodeType::PartiallyVisited => {
                // Reconfiguration (rule (D4)): the old tpq parent edge is
                // replaced by this port-1 edge in set_parent below, which
                // makes the node visited.
                self.node_type[target.index()] = NodeType::Visited;

            NodeType::Visited | NodeType::FullyVisited => {}

        self.set_parent(target, from, edge.remote_port, chosen.port, from_target);
        self.sync_node_type(target);

        // parent, both of which are only settled now that the move is recorded.

        self.apply_parent_vacate(target);
```

```rust
    /// Algorithm 3, `Can_Vacate()`. Decides whether the agent settled at `node`
    /// may leave and travel with the head as a scout.
    ///
    /// The point of vacating is supply: a node only ever holds one settled
    /// agent, so without releasing some of them the head runs out of scouts as
    /// soon as the last agent settles, and the parallel probe has nobody to
    /// probe with. Lemma 4 is what this buys — at least a third of the tree is
    /// vacated at any moment.
    fn apply_can_vacate(&mut self, node: NodeId) {
        let Some(owner) = self.settled_at[node.index()] else {
            return;
        };
        if self.agents[owner.index()].status != P1Status::Settled {
            return;
        }
        // (V1) the root is always occupied.
        if self.parent[node.index()].is_none() {
            return;
        }
        let node_type = self.node_type[node.index()];
        let vacated_neighbor = self.agents[owner.index()].vacated_neighbor;

        match node_type {
            // (V2) a visited node vacates when its port-1 neighbour is occupied.
            // The head steps there to record that this node leaned on it.
            NodeType::Visited => {
                let Some(edge) = self.graph.traverse(node, PORT_ONE) else {
                    return;
                };
                if self.state_of(edge.neighbor) != NodeState::Occupied {
                    return;
                }
                if let Some(neighbor_owner) = self.settled_at[edge.neighbor.index()] {
                    self.agents[neighbor_owner.index()].vacated_neighbor = true;
                }
                // Algorithm 3 lines 4-8: visit the port-1 neighbour and return.
                self.metrics.agent_moves(2);
                self.metrics.vacate();
                self.join_group(owner);
            }
            // (V3) a fullyVisited node vacates unless a neighbour is leaning on
            // it, and (V4) a partiallyVisited node always vacates.
            NodeType::FullyVisited if !vacated_neighbor => {
                self.metrics.vacate();
                self.join_group(owner);
            }
            NodeType::PartiallyVisited => {
                self.metrics.vacate();
                self.join_group(owner);
            }

        }
```

```rust
    /// Section 5.1. Walks the travelling scouts home along the tree.
    ///
    /// The scouts are all standing wherever the head finished. From there the
    /// walk is a depth-first tour of the tree, one edge per step, and each
    /// scout steps off when it reaches the node it owns. A tour crosses every
    /// tree edge at most twice, so this is at most `2(k - 1)` moves, and it
    /// stops as soon as nobody is left travelling.
    fn retrace(&mut self) {
        let mut travelling: Vec<usize> = self
            .agents
            .iter()
            .enumerate()
            .filter(|(_, agent)| agent.status == P1Status::SettledScout)
            .map(|(index, _)| index)
            .collect();
        if travelling.is_empty() {
            return;
        }

        // The tree as undirected adjacency: each node's children in the order
        // the DFS added them, then its parent.
        let mut neighbours: Vec<Vec<NodeId>> = vec![Vec::new(); self.graph.node_count()];
        for index in 0..self.graph.node_count() {
            if let Some((parent, _, _)) = self.parent[index] {
                neighbours[parent.index()].push(NodeId(
                    u32::try_from(index).expect("node count fits the dense ID domain"),
                ));
            }
        }
        for (list, link) in neighbours.iter_mut().zip(&self.parent) {
            if let Some((parent, _, _)) = link {
                list.push(*parent);
            }
        }

        let walk = Self::tour(self.head, &neighbours);
        for (step, &node) in walk.iter().enumerate() {
            if step > 0 {
                self.metrics.logical_rounds(RoundKind::Retrace, 1);
                self.metrics.retrace();
                self.metrics.agent_moves(travelling.len() as u64);
                for &index in &travelling {
                    self.agents[index].node = node;
                }
                self.head = node;
            }
            if let Some(owner) = self.settled_at[node.index()] {
                if let Some(position) = travelling.iter().position(|&i| i == owner.index()) {
                    travelling.remove(position);
                    self.agents[owner.index()].status = P1Status::Settled;
                    self.agents[owner.index()].node = node;
                }
            }
            if step > 0 {
                self.checkpoint(Phase::Retrace);
            }
            if travelling.is_empty() {
                break;
            }
        }
    }
```

## RootedAsync

`RootedAsync` from Pattanayak, Kshemkalyani, Kumar, Molla and Sharma, *Optimal Dispersion Under Asynchrony*, Sections 4–5 and Algorithms 2–6: the P1Tree DFS run **agent by agent**. One activation is one Communicate-Compute-Move cycle: the agent reads the agents at its own node, writes its own memory and at most one other's, and leaves along at most one port. Under the interleaved schedule the read and the write are separate steps, with other agents acting in between.

One agent **leads**. It settles the highest unsettled ID at each new node, sends the group out in probe batches, concludes each probe by rules R1–R3c from what the group remembers, and decides the next edge and who vacates; members carry out its numbered commands. When nobody is left unsettled the lead role passes to a scout and the scouts walk the tree home. The [gap and trace note](2507.01298-optimal-dispersion-under-asynchrony/gap-and-trace-note.md) has the model, the eleven repairs to the pseudocode, and the validation.

**Notes**

- No decision reads the simulator's ownership index. The simulator checks every probe's conclusion, every settle and every arrival against the truth, and stops the run on any disagreement (`LocalViewDisagrees`, `WrongHead`, `NodeClaimedTwice`, `SettledAwayFromHome`).
- Under `Interleaved`, a commit that would write over memory someone else changed since its look fails the run as `WriteConflict`; it never happens in the sweeps.
- At a node of degree at least `k - 1`, `plan_probe` takes Algorithm 5's shortcut: probe enough ports for every unsettled agent to find an empty neighbour, and scatter them there.
- Every vacate needs an occupied node within two port-1 hops, which is then barred from vacating (repair 11), so R3b and R3c-i never misread a vacated node as empty.
- Rooted only: a placement that is not all on one node is refused with `NonRootedStart`. The run stops at the epoch limit as RoundLimitReached.

```rust
/// Runs `RootedAsync` from a rooted placement under `schedule`, stopping after
/// `epoch_limit` epochs.
///
/// # Errors
///
/// Rejects an empty graph, more agents than nodes, a start outside the graph,
/// and a placement that is not rooted. Also returns an error whenever a
/// decision made from the local view is caught out by the simulator's check.
pub fn simulate<M: Metrics, R: Recorder>(
    graph: &PortGraph,
    starts: &[NodeId],
    schedule: Schedule,
    epoch_limit: u64,
    metrics: M,
    recorder: R,
) -> Result<(RootedAsyncResult, M, R), RootedAsyncError> {
    if graph.node_count() == 0 {
        return Err(RootedAsyncError::EmptyGraph);
    }
    let Some(&root) = starts.first() else {
        return Err(RootedAsyncError::NonRootedStart);
    };
    if starts.len() > graph.node_count() {
        return Err(RootedAsyncError::TooManyAgents {
            agents: starts.len(),
            nodes: graph.node_count(),
        });
    }
    if let Some(&bad) = starts.iter().find(|n| n.index() >= graph.node_count()) {
        return Err(RootedAsyncError::InvalidStart(bad));
    }
    if starts.iter().any(|&node| node != root) {
        return Err(RootedAsyncError::NonRootedStart);
    }
    run::Run::new(graph, root, starts.len(), metrics, recorder).run(schedule, epoch_limit)
}
```

```rust
    /// Every agent completes one cycle per round, all reading the state the
    /// round began with: the paper's SYNC model, in which a round is an epoch.
    fn run_synchronous(&mut self, limit: u64) -> Result<Termination, RootedAsyncError> {
        let count = self.world.agents.len();
        loop {
            if self.finished() {
                return Ok(Termination::Completed);
            }
            if self.epoch >= limit {
                return Ok(Termination::RoundLimitReached { limit });
            }
            self.changed = false;
            for index in 0..count {
                self.changed |= self.world.land(agent(index));
                self.refresh(agent(index));
            }
            let actions: Vec<Action> = (0..count)
                .map(|index| activate(&self.world, agent(index)))
                .collect();
            self.activations += count as u64;
            self.apply_round(actions)?;
            self.end_epoch()?;
        }
    }
```

```rust
    /// One agent at a time, in an order the schedule picks: the paper's ASYNC
    /// model with atomic cycles. A move ends the cycle only on arrival, so a
    /// scout can be held on an edge, seen at neither end, for as long as the
    /// schedule leaves it there.
    fn run_asynchronous(
        &mut self,
        limit: u64,
        seed: u64,
        starved: Option<(AgentId, u32)>,
    ) -> Result<Termination, RootedAsyncError> {
        let count = self.world.agents.len();
        let mut rng = DeterministicRng::new(seed);
        let mut completed = vec![false; count];
        let mut remaining = count;
        let mut step = 0_u64;
        loop {
            if self.finished() {
                return Ok(Termination::Completed);
            }
            if self.epoch >= limit {
                return Ok(Termination::RoundLimitReached { limit });
            }
            step += 1;
            let id = match starved {
                Some((slow, period)) if step % u64::from(period) == 0 || count == 1 => slow,
                Some((slow, _)) => {
                    let pick = rng.index(count - 1).expect("count > 1");
                    agent(if pick >= slow.index() { pick + 1 } else { pick })
                }
                None => agent(rng.index(count).expect("at least one agent")),
            };
            self.activations += 1;
            let finished_cycle = if self.world.land(id) {
                self.changed = true;
                self.refresh(id);
                true
            } else {
                let action = activate(&self.world, id);
                let moving = action.depart.is_some();
                self.apply(id, action, false)?;
                !moving
            };
            if finished_cycle && !completed[id.index()] {
                completed[id.index()] = true;
                remaining -= 1;
            }
            if remaining == 0 {
                self.end_epoch()?;
                completed.fill(false);
                remaining = count;
                self.changed = false;
            }
        }
    }
```

```rust
    /// The paper's ASYNC with each cycle split into a look and a later commit;
    /// see [`Schedule::Interleaved`]. A cycle with a move completes on arrival,
    /// as under `Random`.
    fn run_interleaved(&mut self, limit: u64, seed: u64) -> Result<Termination, RootedAsyncError> {
        let count = self.world.agents.len();
        let mut rng = DeterministicRng::new(seed);
        let mut pending: Vec<Option<Pending>> = (0..count).map(|_| None).collect();
        let mut completed = vec![false; count];
        let mut remaining = count;
        // An epoch with no change only proves a deadlock if the one before it
        // had none either: a cycle completing in the first may have looked at
        // a state that has since changed.
        let mut quiet_epochs = 0;
        loop {
            if self.finished() {
                return Ok(Termination::Completed);
            }
            if self.epoch >= limit {
                return Ok(Termination::RoundLimitReached { limit });
            }
            let id = agent(rng.index(count).expect("at least one agent"));
            self.activations += 1;
            let finished_cycle = if self.world.land(id) {
                self.changed = true;
                self.refresh(id);
                true
            } else if let Some(look) = pending[id.index()].take() {
                let moving = look.action.depart.is_some();
                self.commit(id, look)?;
                !moving
            } else {
                let action = activate(&self.world, id);
                let seen_other = action
                    .other
                    .as_ref()
                    .map(|other| self.world.memory(other.id).clone());
                let node = self.world.agents[id.index()].position.node();
                pending[id.index()] = Some(Pending {
                    seen_own: self.world.memory(id).clone(),
                    seen_other,
                    seen_version: self.world.version[node.index()],
                    action,
                });
                false
            };
            if finished_cycle && !completed[id.index()] {
                completed[id.index()] = true;
                remaining -= 1;
            }
            if remaining == 0 {
                quiet_epochs = if self.changed { 0 } else { quiet_epochs + 1 };
                self.end_epoch_after(quiet_epochs >= 2)?;
                completed.fill(false);
                remaining = count;
                self.changed = false;
            }
        }
    }
```

```rust
pub(super) fn activate(world: &World<'_>, id: AgentId) -> Action {
    let mut cx = Cx::new(world, id);
    match cx.me.task {
        Task::Idle => {
            if let Some(state) = cx.me.lead.take() {
                cx.me.lead = lead::act(&mut cx, state);
            } else if cx.me.in_group() {
                follow(&mut cx);
            }
        }
        Task::Probe { port, hop } => probe_step(&mut cx, port, hop),
        Task::Return { remaining } => {
            let port = cx.me.scout.back[usize::from(remaining) - 1];
            cx.me.task = if remaining == 1 {
                Task::Idle
            } else {
                Task::Return {
                    remaining: remaining - 1,
                }
            };
            cx.note(Note::ProbeBack);
            cx.leave(port);
        }
        Task::Errand { rule, stage, seq } => errand_step(&mut cx, rule, stage, seq),
        Task::ErrandBack { remaining, seq } => errand_back(&mut cx, remaining, seq),
        Task::Join { port } => {
            cx.me.task = Task::Idle;
            cx.leave(port);
        }
        Task::Scatter { port, parent } => {
            cx.me.task = Task::ScatterArrive {
                parent,
                port_at_parent: port,
            };
            cx.leave(port);
        }
        Task::ScatterArrive {
            parent,
            port_at_parent,
        } => {
            cx.me.state = AgentState::Settled;
            cx.me.parent = Some((parent, port_at_parent));
            cx.me.parent_port = cx.me.arrival_port;
            cx.me.node_type = crate::common::NodeType::FullyVisited;
            cx.me.task = Task::Idle;
        }
    }
```

```rust
        return;

        return;
```

```rust
/// One hop of a probe walk, (R1)-(R3c). Each hop is decided at the node the
/// scout has just reached, from who is standing there and the arrival port.
fn probe_step(cx: &mut Cx<'_, '_>, port: PortId, hop: u8) {
    let arrival = cx
        .me
        .arrival_port
        .expect("a probing scout arrived somewhere");
    let here = cx.settled_here().map(|m| (m.id, m.node_type));
    cx.me.scout.back[usize::from(hop) - 1] = arrival;
    let reached = match hop {
        1 => {
            cx.me.scout.edge_type = EdgeType::of(port, arrival);
            if let Some(found) = here {
                cx.me.scout.found = Some(found);
                Some(Reached::R1)
            } else {
                // Rule (R2) concludes "empty" here when the scout arrived on
                // port 1. But then the head is y's port-1 neighbour, and (V2)
                // vacates y precisely when that neighbour is occupied: a
                // vacated child of the head would be taken for an empty node.
                // So continue as (R3) with z the head, which costs nothing,
                // since going to z is going home.
                cx.me.scout.via_head = arrival == PORT_ONE;
                None
            }
        }
        2 => {
            cx.me.scout.p1 = here.map(|(id, _)| id);
            cx.me.scout.port_at_p1 = arrival;
            if here.is_some() {
                Some(Reached::R3a)
            } else if arrival == PORT_ONE {
                Some(Reached::R3b)
            } else {
                None
            }
        }
        _ => {
            cx.me.scout.p1p1 = here.map(|(id, _)| id);
            cx.me.scout.port_at_p1p1 = arrival;
            Some(Reached::R3c)
        }
    };
    if let Some(reached) = reached {
        // Algorithm 4 has R3c-i set its result without returning; every
        // scout returns.
        cx.me.scout.reached = reached;
        let moves = if cx.me.scout.via_head { hop - 2 } else { hop };
        if moves == 0 {
            cx.me.task = Task::Idle;
            return;
        }
        cx.me.task = if moves == 1 {
            Task::Idle
        } else {
            Task::Return {
                remaining: moves - 1,
            }
        };
        cx.note(Note::ProbeBack);
        cx.leave(cx.me.scout.back[usize::from(hop) - 1]);
    } else {
        cx.me.task = Task::Probe { port, hop: hop + 1 };
        cx.note(Note::ProbeOut);
        cx.leave(PORT_ONE);
    }
}
```

```rust
/// Algorithm 3's excursions: the settled agent at the head walks along
/// port-1 links, looks, writes into the agent it finds, and walks back.
///
/// Rules (R1)-(R3c) can only recognise a vacated node whose port-1 neighbour,
/// or that neighbour's port-1 neighbour, is occupied, and only for as long as
/// that node stays occupied. The paper checks this for (V2) alone: (V3) and
/// (V4) vacate unconditionally, and nothing stops an occupied node that others
/// rely on from vacating later. So (V2), (V3) and (V4) all walk the chain here,
/// and the occupied node they rely on is marked with `vacated_neighbor`, which
/// then keeps it from vacating under any rule.
fn errand_step(cx: &mut Cx<'_, '_>, rule: VacateRule, stage: u8, seq: u32) {
    let here = cx
        .settled_here()
        .map(|m| (m.id, m.parent_port, m.vacated_neighbor));
    let arrival = cx.me.arrival_port;
    let next = |stage| Task::Errand { rule, stage, seq };
    match (rule, stage) {
        (VacateRule::V5, 0) => {
            cx.me.task = next(1);
            cx.leave(cx.me.parent_port.expect("V5 needs a parent"));
        }
        (_, 0) => {
            cx.me.task = next(1);
            cx.leave(PORT_ONE);
        }
        (VacateRule::V5, _) => {
            let arrival = arrival.expect("the errand arrived");
            cx.me.scout.back[0] = arrival;
            let me = cx.me.id;
            let parent_port = cx.me.parent_port;
            cx.me.errand = Some(match here {
                // (V5): the parent goes instead. Its port 1 leads here, so this
                // node is its port-1 neighbour, which Algorithm 3 forgets to
                // record and rule (R3a) needs.
                Some((z, Some(_), false)) => {
                    let parent = cx.write(z);
                    parent.state = AgentState::SettledScout;
                    parent.p1_neighbor = Some(me);
                    parent.port_at_p1_neighbor = parent_port;
                    parent.task = Task::Join { port: arrival };
                    parent.seen_seq = seq;
                    cx.me.vacated_neighbor = true;
                    ErrandResult::Joined
                }
                _ => ErrandResult::NotJoined,
            });
            go_back(cx, 1, seq);
        }
        (_, 1) => {
            let arrival = arrival.expect("the errand arrived");
            cx.me.scout.back[0] = arrival;
            if let Some((w, _, _)) = here {
                cx.write(w).vacated_neighbor = true;
                cx.me.errand = Some(ErrandResult::Anchored {
                    p1: w,
                    port_at_p1: arrival,
                });
                go_back(cx, 1, seq);
            } else if rule == VacateRule::V2 || arrival == PORT_ONE {
                // (V2) asks for an occupied port-1 neighbour, nothing further.
                // Otherwise a second hop is allowed, unless it would lead
                // straight back to this node.
                cx.me.errand = Some(ErrandResult::Refused);
                go_back(cx, 1, seq);
            } else {
                cx.me.task = next(2);
                cx.leave(PORT_ONE);
            }
        }
        _ => {
            let arrival = arrival.expect("the errand arrived");
            cx.me.scout.back[1] = arrival;
            cx.me.errand = Some(match here {
                Some((u, _, _)) => {
                    cx.write(u).vacated_neighbor = true;
                    ErrandResult::TwoHops {
                        anchor: u,
                        port_at_anchor: arrival,
                        port_at_p1: cx.me.scout.back[0],
                    }
                }
                None => ErrandResult::Refused,
            });
            go_back(cx, 2, seq);
        }
    }
}
```

```rust
                .map(|m| m.id)
                .max()
                .expect("the lead itself is unsettled");
            let sibling = lead.sibling_details.take();
            let settle = |m: &mut Memory| {
                m.state = AgentState::Settled;
                m.node_type = NodeType::Visited;
                m.parent = parent_link;
                m.parent_port = arrival;
                m.parent_edge_type = edge;
                m.port_one_tree_edge = edge.is_some_and(EdgeType::is_port_one_incident);
                // Line 25 sets `sibling` on every pass, which on a backtrack
                // overwrites it with nothing; it is set once, here.
                m.sibling = sibling;
            };
            if settler == cx.me.id {
                settle(&mut cx.me);
            } else {
                settle(cx.write(settler));
            }
            lead.child_port = None;
            lead.head_owner = Some(settler);
            lead.unsettled -= 1;
            lead.group_size -= 1;
            if lead.unsettled == 0 {
                return begin_retrace(cx, lead);
            }
        }
        Target::Owner { id, forward } => {
            lead.head_owner = Some(id);
            cx.note(Note::HeadOwner(id));
            if forward {
                // Rule (D4): a partiallyVisited node reached through its port 1
                // swaps its tpq parent edge for this one.
                let sibling = lead.sibling_details.take();
                let owner = cx.write(id);
                owner.old_parent = owner.parent;
                owner.old_parent_port = owner.parent_port;
                owner.old_sibling = owner.sibling;
                owner.parent = parent_link;
                owner.parent_port = arrival;
                owner.parent_edge_type = edge;
                owner.port_one_tree_edge = true;
                owner.node_type = NodeType::Visited;
                owner.sibling = sibling;
                lead.child_port = None;
            }
        }
    }
    issue(cx, &mut lead, Command::Rank);
    rank(cx);
    lead.phase = Phase::Rank;
    Some(lead)
}
```

```rust
/// Every scout of a batch is back: conclude each probe from what the group
/// holds (Algorithm 4 lines 25-50) and keep the best edge so far.
fn finish_batch(cx: &mut Cx<'_, '_>, lead: &mut Lead, first: u16) {
    let pool = cx.group_here();
    let claimants = Claimants::new(&pool);
    let probe_seq = lead.seq;
    for scout in pool.iter().filter(|m| m.scout.seq == probe_seq) {
        let resolution = resolve(&scout.scout, &claimants);
        cx.note(Note::Probed {
            head: cx.node,
            resolution,
        });
        let eligible = match resolution.node_type {
            NodeType::Unvisited => resolution.owner.is_none(),
            // Rule (D4): enterable through its port 1 only.
            NodeType::PartiallyVisited => {
                matches!(scout.scout.edge_type, EdgeType::OtherOne | EdgeType::OneOne)
            }
            NodeType::Visited | NodeType::FullyVisited => false,
        };
        let candidate = Candidate {
            port: resolution.port,
            edge_type: scout.scout.edge_type,
            owner: resolution.owner,
        };
        let rank = |c: &Candidate| (c.edge_type.priority(), c.port.0);
        if eligible
            && lead
                .best
                .map_or(true, |best| rank(&candidate) < rank(&best))
        {
            lead.best = Some(candidate);
        }
    }
    if lead.scatter_mode {
        issue(cx, lead, Command::Collect { probe_seq });
        tally(&mut cx.me, &pool, probe_seq);
        lead.phase = Phase::Collect { first };
    } else {
        next_batch_or_decide(cx, lead, first + lead.batch);
    }
}
```

```rust
///
/// `claimants` indexes the group as it stands at the head. A vacated node's
/// agent is in it, so a vacated node is recognised by finding the group member
/// whose stored port-1 neighbour is the one the scout saw.
pub(super) fn resolve(scout: &ScoutRecord, claimants: &Claimants<'_>) -> Resolution {
    let claimant = |p1: AgentId, port: PortId| claimants.find(p1, port);
    let empty = |rule| Resolution {
        port: scout.port,
        owner: None,
        node_type: NodeType::Unvisited,
        rule,
    };
    let vacated = |member: &Memory, rule| Resolution {
        port: scout.port,
        owner: Some(member.id),
        node_type: member.node_type,
        rule,
    };

    match scout.reached {
        Reached::R1 => {
            let (owner, node_type) = scout.found.expect("R1 records who was home");
            Resolution {
                port: scout.port,
                owner: Some(owner),
                node_type,
                rule: ProbeRule::R1,
            }
        }
        Reached::R3b => empty(ProbeRule::R3b),
        Reached::R3a => {
            let z = scout.p1.expect("R3a records who was at z");
            claimant(z, scout.port_at_p1)
                .map_or_else(|| empty(ProbeRule::R3aII), |b| vacated(b, ProbeRule::R3aI))
        }
        Reached::R3c => {
            let Some(w) = scout.p1p1 else {
                return empty(ProbeRule::R3cI);
            };
            // c = psi(z), recognised by its own port-1 neighbour w; then
            // b = psi(y), recognised by having c as its port-1 neighbour.
            claimant(w, scout.port_at_p1p1)
                .and_then(|c| claimant(c.id, scout.port_at_p1))
                .map_or_else(
                    || empty(ProbeRule::R3cIIBeta),
                    |b| vacated(b, ProbeRule::R3cIIAlpha),
                )
        }
    }
```

```rust
/// edge, and decide whether its agent vacates.
fn decide(cx: &mut Cx<'_, '_>, lead: &mut Lead) {
    cx.note(Note::MacroRound);
    let owner_id = lead.head_owner.expect("the head has an owner");
    let mut owner = owner_memory(cx, lead);

    // Line 21, and Claim 3 for a dead end: a node with only a tpq parent edge
    // and no port-1 tree edge waits for its port-1 neighbour.
    let waiting = owner
        .parent_edge_type
        .is_some_and(|t| !t.is_port_one_incident())
        && !owner.port_one_tree_edge;
    let (node_type, plan) = match lead.best {
        Some(c) if waiting && !c.edge_type.is_port_one_incident() => {
            (NodeType::PartiallyVisited, Plan::Back)
        }
        Some(c) => (NodeType::Visited, Plan::Forward(c)),
        None if waiting => (NodeType::PartiallyVisited, Plan::Back),
        None => (NodeType::FullyVisited, Plan::Back),
    };
    if plan == Plan::Back && owner.parent.is_none() {
        cx.note(Note::Stuck(
            "the root ran out of edges with agents unsettled",
        ));
        return;
    }
    owner.node_type = node_type;
    lead.plan = plan;

    // Algorithm 3, read with the prose of Section 4.1. As printed, its
    // `visited` branch always returns, so rule (V5) could never fire for the
    // child Lemma 3 applies it to; here V5 is tried whenever this node stays.
    // A node others rely on (`vacated_neighbor`) never vacates; see
    // `agent::errand_step` for why that has to cover every rule.
    let own_rule = match node_type {
        _ if owner.state != AgentState::Settled || owner.parent_port.is_none() => None,
        _ if owner.vacated_neighbor => None,
        NodeType::Visited => Some(VacateRule::V2),
        NodeType::FullyVisited => Some(VacateRule::V3),
        NodeType::PartiallyVisited => Some(VacateRule::V4),
        NodeType::Unvisited => None,
    };
    let rule = own_rule.or_else(|| v5_applies(&owner).then_some(VacateRule::V5));
    if let Some(rule) = rule {
        start_errand(&mut owner, lead, rule);
    } else {
        lead.phase = Phase::PreMove;
    }
    write_owner(cx, owner_id, owner);
}
```

```rust
/// pick the next node of the post-order walk.
fn retrace_step(cx: &mut Cx<'_, '_>, mut lead: Lead) -> Option<Lead> {
    let arrival = cx.me.arrival_port;
    let owner_id = if let Some(settled) = cx.settled_here() {
        settled.id
    } else {
        let Some(next) = lead.next_agent_id else {
            cx.note(Note::Stuck(
                "retrace reached an empty node with no one expected",
            ));
            return Some(lead);
        };
        let Some(found) = cx
            .find(next)
            .filter(|m| m.state == AgentState::SettledScout)
        else {
            cx.note(Note::Stuck(
                "retrace expected an agent the group does not have",
            ));
            return Some(lead);
        };
        let id = found.id;
        if id == cx.me.id {
            cx.me.state = AgentState::Settled;
        } else {
            cx.write(id).state = AgentState::Settled;
        }
        lead.group_size -= 1;
        id
    };
    if lead.group_size == 0 {
        return None;
    }

    let mut owner = cx.find(owner_id).expect("just found").clone();
    let mut sibling = lead.sibling_details;
    let to_parent = |owner: &Memory| {
        (
            owner.parent.map(|(id, _)| id),
            owner.parent_port,
            owner.sibling,
        )
    };
    let reconfigured_back = owner.old_parent_port.is_some()
        && arrival == owner.old_parent_port
        && arrival != owner.parent_port;
    let (next_agent, next_port) = if reconfigured_back {
        // Reached through the old parent's chain of children, which still
        // lists this node from before its reconfiguration. Treat it as the
        // leaf it was there and go back the way the group came.
        sibling = owner.old_sibling;
        (owner.old_parent.map(|(id, _)| id), arrival)
    } else if let Some(child) = owner.recent_child {
        if Some(child) == arrival {
            if let Some((id, port)) = lead.sibling_details {
                // Lines 19-21: across to the previous sibling.
                sibling = None;
                owner.recent_child = Some(port);
                (Some(id), Some(port))
            } else {
                // Lines 15-17: no more children, up to the parent.
                owner.recent_child = None;
                let (id, port, next_sibling) = to_parent(&owner);
                sibling = next_sibling;
                (id, port)
            }
        } else {
            // Lines 23-27: down to the most recent child, expecting its agent
            // if the group holds it. A reconfigured child is matched by its
            // old parent link too.
            let me = owner.id;
            let expected = cx
                .group_here()
                .into_iter()
                .find(|m| m.parent == Some((me, child)) || m.old_parent == Some((me, child)))
                .map(|m| m.id);
            (expected, Some(child))
        }
    } else {
        // Lines 29-32: a leaf, up to the parent.
        let (id, port, next_sibling) = to_parent(&owner);
        sibling = next_sibling;
        (id, port)
    };
    let Some(port) = next_port else {

            "retrace ran past the root with agents still away",
        ));
        return Some(lead);
    };
    lead.next_agent_id = next_agent;

    cx.note(Note::RetraceMove);

        // issues the move this cycle chose.

            lead: None,
            ..owner
        };

            .map(|m| m.id)
            .min()
            .expect("the group is not empty");

        return None;
    }
    write_owner(cx, owner_id, owner);
    issue(cx, &mut lead, Command::Move { port });
    lead.phase = Phase::RetraceDepart;
    Some(lead)
```

## RootedDisp

`RootedDisp` from Sudo, Shibata, Nakamura, Kim and Masuzawa, *Near-linear Time Dispersion of Mobile Agents*, Section 3 and Algorithm 1: the rooted HEO-DFS. The agent with the largest ID leads a depth-first search, and the smallest-ID explorer settles at each node it reaches. Every box that moves agents is exactly one synchronous step, committed through `apply_move_intents`; settling takes none. [rooted-disp.md](rooted-disp.md) has the time model, the decisions taken where Algorithm 1 leaves a choice, and two worked traces.

What makes the search fast is `probe_pass`. Every agent at the node except its settler takes one port; a settler found at home comes back as a **helper** and probes in the next pass too, so the probers double until one finds an unsettled neighbour: `O(log τ)` passes per probe and `O(k log τ)` steps in all. `probe` resets `next` and `checked` on every call, so no cursor survives from an earlier visit.

**Notes**

- Rooted only: every agent must start on one node. Any other placement is refused with `NonRootedStart` before the first step.
- Two choices Algorithm 1 leaves open (rooted-disp.md, decisions 1 and 2): the helpers walk home in a step of their own, taken only when there are helpers; and probers take ports in ascending ID, the smallest unsettled port winning.
- A retreat at the root would mean the root's component has fewer nodes than agents; the run returns `RootExhausted` instead of looping.
- Round limit: `commit` checks it before every step, so a run can stop between the passes of a probe and returns its partial state as RoundLimitReached.

```rust
    /// One pass of `Probe()`'s while loop, lines 16–21. Returns the port of
    /// an unsettled neighbour if a prober found one.
    fn probe_pass(
        &mut self,
        w: NodeId,
        psi: AgentId,
        first: u16,
        degree: u16,
    ) -> Result<Option<PortId>, Halt> {
        // Line 16: every agent at w but ψ(w), in ascending ID (decision 2),
        // takes one of the next Δ′ ports. Recruited helpers probe too.
        self.probers.clear();
        self.probers.extend_from_slice(&self.explorers);
        self.probers.extend_from_slice(&self.helpers);
        self.probers.sort_unstable();
        let count = self.probers.len().min(usize::from(degree - first));
        self.assigned.clear();
        self.intents.clear();
        for (offset, &agent) in self.probers[..count].iter().enumerate() {
            let port = PortId(first + u16::try_from(offset).expect("offset is below the degree"));
            self.assigned.push((agent, port));
            self.intents.push(MoveIntent {
                agent,
                from: w,
                port,
            });
        }
        self.commit(Step::ProbeOut)?;
        for _ in 0..count {
            self.metrics.port_probe();
            self.metrics.probe_out_traversal();
        }
        self.record(Phase::ProbeOut);

        // Line 17: each prober looks at the agents on the node it stands on.
        // A settler at home there comes back with it; finding nobody means
        // the node is unsettled.
        self.found.clear();
        self.intents.clear();
        let mut unsettled: Option<PortId> = None;
        for index in 0..self.assigned.len() {
            let (agent, port) = self.assigned[index];
            let state = *self.state(agent);
            let back = state
                .arrival_port
                .ok_or(broken(InvariantViolation::InvalidTraversal))?;
            self.intents.push(MoveIntent {
                agent,
                from: state.node,
                port: back,
            });
            if let Some(settler) = self.store.settled_agent_at(state.node) {
                self.found.push((agent, settler));
                self.intents.push(MoveIntent {
                    agent: settler,
                    from: state.node,
                    port: back,
                });
            } else {
                // Every settler is home when a Probe() starts, and helpers
                // come only from ports already checked, so an owner that is
                // away here would mean the model was broken.
                if self.store.home_owner(state.node).is_some() {
                    return Err(broken(InvariantViolation::OwnershipIndexMismatch).into());
                }
                // Decision 2: the smallest such port wins.
                unsettled = Some(unsettled.map_or(port, |best: PortId| best.min(port)));
            }
        }
        self.commit(Step::ProbeBack)?;
        for _ in 0..count {
            self.metrics.probe_back_traversal();
        }
        for index in 0..self.found.len() {
            let (_, settler) = self.found[index];
            self.store.vacate_home(settler)?;
            // The helper's way home is the port it just arrived through.
            self.memory[settler.index()].return_port = self.state(settler).arrival_port;
            self.helpers.push(settler);
            self.stats.helper_recruitments += 1;
            if self.recorder.enabled() {
                self.events.push(SimulationEvent::AgentStateChanged {
                    agent: settler,
                    from: AgentStatus::Settled,
                    to: AgentStatus::SettledScout,
                });
            }
        }
        self.record(Phase::ProbeBack);

        if unsettled.is_some() {
            return Ok(unsettled);
        }
        // Line 21: every prober brought a settler back.
        let last = first + u16::try_from(count - 1).expect("count is at most the degree");
        self.memory[psi.index()].checked = Some(PortId(last));
        Ok(None)
    }
```

## Reading the four together

All four settle one agent per node and all four are depth-first, but they
differ in who does the looking and what the tree is for.

| | Drop and Freeze | Help by Scouts | P1Tree | RootedDisp |
| --- | --- | --- | --- | --- |
| Start | one node (several are accepted but can stall) | one node | one node (required) | one node (required) |
| Who probes | unsettled agents, one per port | unsettled agents plus vacated settlers | unsettled agents plus vacated settlers | explorers plus settlers recruited as helpers during the probe |
| Probe cost | one port per agent per round | parallel across scouts | parallel, and stops at the first find | probers double each pass; `O(log τ)` passes |
| Port labels | overwritten by `canonicalize_ports` | as given | as given, and central to the result | as given |
| Tree | incidental to the walk | carries the retrace | the object being built | parent ports for backtracking |
| Stops when | every agent is settled, or the round limit | every agent is settled, or the round limit | every agent is settled, or the round limit | the leader settles, last, or the round limit |

The port-label row is the one that catches people out. Drop-and-Freeze discards
the port assignment an experiment asked for, so sweeping `--ports` changes
nothing for it; P1Tree's whole behaviour turns on which edges happen to carry
port 1.
